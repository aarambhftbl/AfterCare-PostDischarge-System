# AfterCare 🏥: Post-Discharge Management System

### 🎥 [WATCH THE DEMO VIDEO HERE](PASTE_YOUR_VIDEO_LINK_HERE)

## Problem Statement
Addressing **Problem Statement 4**: Hospitals lack centralized follow-up systems. Patients struggle with manual tracking of medications and appointments after discharge.

## The Solution
**AfterCare** is a web platform that digitizes the recovery journey.
* **Innovation:** "Smart Scan" feature uses simulated OCR to read prescriptions and auto-schedule meds.
* **Tech Stack:** Python (Flask), SQLite, Bootstrap 5.

## Key Features
1. **Smart Document Scanner:** Upload a prescription image to auto-fill medication logs.
2. **Follow-Up Scheduler:** Tracks doctor visits.
3. **Medication Dashboard:** Prevents dosage errors.

## How to Run
1. `pip install -r requirements.txt`
2. `python app.py`
3. Access at localhost:9999
